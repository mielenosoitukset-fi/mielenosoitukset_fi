- The event submission form now says which field failed when it rejects a submission, such as an unknown city, an invalid organizer email or an expired form session. Before, every rejection showed the same "Tarkista lomakkeen tiedot ja hyväksy käyttöehdot" message with code `SUBMIT_MISSING_FIELDS`, even when no field was missing. Format errors now use the code `SUBMIT_INVALID_FIELD` and image errors use `SUBMIT_INVALID_IMAGE`. The server logs which check failed, without the submitted values.
