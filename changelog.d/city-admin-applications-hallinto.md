- City admin applications sent from `/kaupunkiadmin` can be handled in Hallinto. Hallinto reads them and records the case and the applicant's status through the Hallinto issuer. With `CITY_ADMIN_APPLICATIONS_IN_HALLINTO=true` the delivery job stops making admin cases, and an application handled in Hallinto can no longer be decided in the admin case view. The flag is off by default, so the current flow is unchanged.
