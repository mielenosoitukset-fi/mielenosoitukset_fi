- Admin account deletions can now be reviewed in Hallinto. With `ACCOUNT_DELETION_IN_HALLINTO=true`, deleting a user in the admin closes the account (it cannot sign in, sessions and keys end, nothing is erased) and OT decides in Hallinto whether to erase it or restore it. The user list shows "Poisto odottaa OT:n tarkistusta" for these accounts. Users deleting their own account and erasure requests stay instant. The flag is off by default, so the current instant delete is unchanged.
