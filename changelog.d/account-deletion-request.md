- Signed-in users can ask for their account to be deleted from the Security tab of the React settings page. The request opens an admin case ("Tilin poistopyyntö") with an optional reason; an admin deletes the account through the existing admin delete, which follows the erasure rules in `docs/account-erasure.md`. Without the Go account writes, the card points to the support address instead. The Go route `POST /api/account/deletion-request` ships behind `ACCOUNT_SETTINGS_WRITES_ENABLED` and its Apache rule is commented out until the settings writes are activated.
